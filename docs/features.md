# Minis Linux 功能说明

Minis Linux 是部署在自有 Linux 主机上的单用户 AI 助手。它在主机上管理会话、技能、记忆和工作区工具，并把模型请求发往你配置的服务。本文标注了新增功能所需的版本；可用版本见 [GitHub Releases](https://github.com/brucelau1987cn/minis-linux/releases)。

## 对话入口

### Telegram 私聊

通过一个专用 Bot 聊天、调用技能和管理记忆，不用切换模式。Minis 通过 Telegram Bot API 长轮询接收消息，不需要开放入站端口。只处理配置中指定账号发来的私聊消息，不接受群聊或转发消息。

在已配置的 Bot 私聊中发送 `/status` 检查消息收发，再发一句普通消息验证模型。`/status` 不调用模型。发送 `/help` 查看命令。v0.4 的 `/new [标题]` 开一个新会话，不删除本机旧会话或 Telegram 消息。

### 查看进度与停止任务（v0.3 起）

Bot 接到任务后先发回执。模型请求在后台执行，等待时仍可发送 `/status` 查看当前阶段。任务结束后，`/status` 会显示上一次任务的结果状态。

开始保存和发送结果前，可用 `/stop` 放弃本轮。Minis 不保存被停止的对话，也不发送迟到的结果；已经显示的流式片段可能仍然可见，已经发出的模型请求也可能继续执行。在旧请求退出前，Bot 不接收新的模型任务。若要在任务进行中开启新会话，先发 `/stop`，再发 `/new`。

### 交互式终端

安装后运行 `minis` 打开终端对话。启动面板显示当前模型、网关主机名、可用工具和技能；输入区旁的状态行显示当前模型和上一轮耗时。界面保留 SSH 终端滚屏，窄窗口或 `minis --plain` 使用简洁提示。首次启动可填写模型配置，也可预先提供 `MINIS_BASE_URL`、`MINIS_MODEL` 和 `MINIS_API_KEY`。终端与 Telegram 分别保存设置、工作区、会话和记忆，不会自动同步。发送 `/exit` 退出终端。

如果只想试界面，在解压目录中运行 `python3 minis_cli.py --demo`。该演示使用固定的本地响应，不调用模型，也不修改正式会话。

只使用终端时，可运行 `/usr/bin/python3 -EsB install.py --user`，不需要 `sudo` 或 Telegram 凭据。程序在 `~/.minis/app/`，终端状态在 `~/.minis/terminal/`。如果 `~/.local/bin` 不在 `PATH`，可先运行 `export PATH="$HOME/.local/bin:$PATH"`，或直接执行 `~/.local/bin/minis`。Telegram 仍按[常驻部署手册](../systemd/README.md)单独安装和配置。

### 设置终端默认模型（v0.3 起）

退出当前终端对话后运行 `minis model`。先选已有网关或添加新网关，再输入关键词筛选模型，用 ↑↓ 移动、Enter 确认、Esc 取消。终端不支持此菜单时会改用编号选择。添加网关需要名称、OpenAI 兼容 Base URL 和 API Key，密钥不回显；已有网关沿用各自的凭据，添加另一个网关不会覆盖它。目录不可用时可手动输入模型 ID。选模只拉取目录，不调用推理接口，也不验证模型推理权限。

已配置网关时可直接运行 `minis model MODEL_ID`，在默认网关上保存指定模型，不请求模型目录；`minis model --show` 查看已保存的默认模型，不显示 API Key。新设置在下次打开 `minis` 时生效。更换默认网关时，Minis 会显示目标并提示已有对话和长期记忆可能随请求发送，只有确认后才保存。

终端对话中输入 `/model` 可从已配置网关选模型，或输入 `/model MODEL_ID` 在当前网关直接切换。下一条消息就用新模型，不写入默认设置，也不用退出会话。保留当前对话意味着**切换网关后，后续请求会将对话上下文发给新网关**；不想把这段对话发过去，可以先用 `/new` 开启新会话。长期记忆仍保留，并可能随请求发出。以上操作不改变 Telegram 服务的配置。

## 技能、工作区与记忆

### 按需加载技能

技能是本机安装的 `SKILL.md` 文件，用来描述一类任务的处理步骤。Minis 先把技能目录提供给模型，模型需要时才读取正文。发送 `/skills` 查看已装技能；使用时可以直接提需求，不必先选择技能或切换模式。

例如，将脱敏的值班记录放入工作区后，在私聊中发送：

> 使用 `weekly-report` 技能读取 `handover.md`，按已完成、风险和下一步整理中文周报。缺少的信息标记为待确认。

仓库提供一个 [周报技能示例](../skills/weekly-report/SKILL.md)。默认 systemd 部署从 `/opt/minis-linux/skills/<名称>/SKILL.md` 加载技能。技能文本可以指导模型使用已有工具，但不会授予新权限；Minis 不执行技能附带的脚本。

### 网页搜索（终端）

在终端对话中输入 `/search Debian 安全公告`，Minis 通过 [DuckDuckGo Lite](https://lite.duckduckgo.com/lite/) 返回最多 5 条标题、链接和搜索摘要。无需搜索 API Key，也不调用模型，不自动打开结果网页。只有输入的关键词会发送给 DuckDuckGo；不要搜索密钥或内部资料。Lite 不是有可用性承诺的搜索 API，遇到限流、验证页或页面格式变化时会提示，不绕过验证。离线演示和 Telegram 不提供此命令。

### 本机时间和磁盘余量

终端和 Telegram 都可以用普通消息询问日期、星期、时间或工作区磁盘余量。Minis 从运行主机读取时间，并报告主机时区与 UTC 偏移，不假设它与你所在地相同。模型每轮获得一份服务器时间快照，需要时可重新查询。`/time` 和 `/disk` 直接查询，不调用模型；磁盘仅报告工作区所在文件系统的容量，不接受其他路径。

### 工作区与操作审批（v0.4）

两个入口分别使用各自的工作区。模型可读取顶层普通 UTF-8 文本，也可提议创建、修改或移入回收站；实际操作由你在同一会话看完预览后单独发 `/approve ID` 执行。用 `/actions` 查待办，`/preview ID` 重看预览，`/cancel ID` 取消，`/audit` 看执行记录。`/trash` 和 `/restore ID` 可预览恢复。创建和恢复不覆盖文件；编辑或回收时目标发生变化则需重新提议。没有 Shell、递归删除或永久删除命令。

用 `/skill import 文件名` 从工作区提议导入 `SKILL.md`。模型也可以起草文本技能，确认后保存。确认不会执行技能脚本或安装依赖。

### 查找、导出与输入（v0.4）

- `/sessions` 列出会话，`/session ID` 切换，`/title 标题` 重命名，`/history 关键词` 搜索当前入口的历史。`/export [ID]` 创建 Markdown 导出预览。确认后，终端将新文件保存在私有目录 `~/.minis/terminal/exports/`（自定义状态目录时为该目录下的 `exports/`），并显示完整路径；模型工具不能读取这个目录。Telegram 以附件发回授权私聊；如果无法确认送达，请先检查私聊，Minis 不会重发。脱敏是尽力而为，分享前请人工检查。
  旧版已写入工作区的导出文件不会自动移动；请自行移出工作区或删除不再需要的副本。
- 两个入口都可明确要求搜索，或单独发送一个公开 HTTP(S) 链接，也可输入「打开 链接」。普通聊天里提到链接不会触发读取，搜索不会自动打开结果，程序拒绝疑似带凭据的链接。网页整理不使用会话、长期记忆、技能或工作区，也不存入聊天历史。它会在核对完整回复后显示摘要和来源。
- 支持的终端可用 `Ctrl+J` 换行、`Tab` 切换命令建议，整段粘贴先留在输入区，按 Enter 才提交。带括号标记的粘贴不会作为本地命令执行。`--plain` 保留普通输入与整条回复。

### 显式长期记忆

- `记住：周报用中文`：保存一条偏好。
- `查看记忆`：列出当前入口的记忆和编号。
- `忘记第 1 条`：删除对应编号的记忆。

普通对话不会自动写入长期记忆，`/new` 也不会清除它。v0.4 允许模型提出记忆建议，不经审批不保存。记忆以明文保存在本机，后续模型请求会携带当前条目。删除记忆不会移除旧对话、Telegram 或模型服务已经保存的副本。

## 模型接入与数据边界

Minis 使用 OpenAI 兼容的 `POST /v1/chat/completions`，可连接 CLIProxyAPI（CPA），也可连接其他支持工具调用的兼容服务。配置包含 Base URL（例如 `https://api.example.com/v1`）、模型 ID 和普通调用 API Key。使用 CPA 时不要填管理密钥。

Minis 在 Linux 主机上执行工具并保存状态；模型推理由配置的服务完成。发送给模型的内容可包括当前对话、保存的记忆、技能正文和工具读取的文本。不要将密钥或不适合发给模型的资料放进工作区、技能或记忆。

## 部署与版本维护

- **常驻运行。** 安装向导注册 systemd 服务。Bot 以非 root 身份运行，可随系统启动，并在异常退出时按服务配置重启。
- **检查版本。** `minis --version` 显示已安装版本；`minis update --check` 查找更新，不安装或重启服务。
- **升级。** `minis update` 校验更新标签签名后安装较新的稳定版，不跟随开发分支。升级保留现有配置、凭据、技能和聊天数据。安装器在本机检查新服务启动，失败时尝试回退，强制中断后可按部署手册恢复。

首次安装、凭据保护、日志检查和回退步骤见 [systemd 部署手册](../systemd/README.md)。
